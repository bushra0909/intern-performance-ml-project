# Intern Performance Prediction ML Project

## Overview

This project predicts intern performance based on:

- Task completion time
- Feedback ratings
- Attendance records

## Model Used

Random Forest Regressor (Machine Learning - Ensemble Method)

## How it works

- Loads dataset using pandas
- Splits data into training and testing sets
- Trains ML model using RandomForest
- Predicts performance score
- Classifies interns into:
  - Excellent ⭐
  - Average ⚠️
  - Struggling ❌

## Tech Stack

- Python
- Pandas
- Scikit-learn

## Output

Model predicts a performance score between 0 and 1.
